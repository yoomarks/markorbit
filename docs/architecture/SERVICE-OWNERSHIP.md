# Service Ownership

| Service | Owns | Does not own |
|---|---|---|
| Core | identity references, Workplace membership, shared semantics, permission references | Product workflows, AI recommendations, provider admission |
| Knowledge | source ingestion references, ready-package query, provenance and freshness | Capability verification, recommendations, Matter state |
| Capability Engine | capability registry/version, composition, context compilation, invocation and change candidates | task completion, provider authority, official state |
| Execution | plans, work packages, tasks, reviews, approvals, evidence requests and session receipts | Product pricing, professional qualification, official filing |
| MarkReg | trademark intake, recommendation package, quote/order/matter domain and lifecycle instructions | provider network admission, user capability profile |
| MGSN | provider organization, Provider Supply Capability, service package, eligibility, allocation, acceptance and return | customer relationship ownership, Official Truth |
| Lite | professional product experience, content, opportunities, assets and Capability Profile projection | shared canonical state or direct provider database writes |
| markreg.com | direct-customer acquisition, guided submission and lifecycle experience | professional operating console or provider internals |
