# Four-week Beta Plan

## Week 1 — Foundation and first thin slices

- repository quality gate and local infrastructure;
- contracts, auth references and event envelope;
- independent service health and ownership boundaries;
- Lite and markreg.com UI briefs and shells;
- direct consultation → Intake → fixture recommendation;
- professional customer → Intake → review fixture.

Exit: both products call real service endpoints and display persisted Intake state.

## Week 2 — Attraction and recommendation

- Lite Today, Content Studio, Opportunities, Trademark Assets and Capability Tree v1;
- MarkReg jurisdiction, class, goods, documents and quote recommendations;
- markreg.com guided intake, plan selection and order confirmation;
- Capability registry, composition, context package and Session Receipt;
- Knowledge provenance query fixtures.

Exit: one trademark can produce a recommendation, content package and opportunity with traceable sources.

## Week 3 — Delivery loop

- Intake to Matter;
- Execution plans, work packages, review, approval and evidence;
- MGSN provider registry, supply capability, eligibility, allocation, acceptance and return;
- Lite work surfaces;
- markreg.com customer actions, documents and Matter timeline.

Exit: recommendation → Matter → Provider Return → evidence review runs end to end.

## Week 4 — Learning, hardening and Beta release

- Capability Profile, Twin projection, Ledger and private Reflection Candidate;
- content and opportunity conversion analytics;
- lifecycle reminders and recommended actions;
- permission, isolation, idempotency, retry and recovery tests;
- seeded demo, E2E suites and deployment rehearsal.

Exit: Beta release candidate with three complete loops and explicit known limits.
