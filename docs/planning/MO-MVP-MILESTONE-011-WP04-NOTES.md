# M11 WP04 — Management Recommendation Preparer

This work package converts existing M11 Management Signals into deterministic, reviewable Product recommendations.

## Boundary

Recommendations may prepare bounded owner-work, Today or Content candidates for review. They do not verify official truth, certify a legal deadline, resolve source conflict, file, contact a customer/provider/authority, authorize payment, publish externally, verify Capability, or bypass owner-domain validation.

## Mapping

- observed-date proximity / freshness / conflict -> verify source or deadline;
- missing consequential context -> gather missing information;
- lifecycle relevance -> review lifecycle recommendation, or prepare owner-work candidate only when matching bounded AI Guide context exists;
- Knowledge relevance -> prepare Today candidate, or Content candidate only when matching bounded AI Guide context exists;
- user priority -> prepare Today candidate;
- repeated portfolio pattern -> watch.

Every consequence still requires explicit user review and later governed handoff.
