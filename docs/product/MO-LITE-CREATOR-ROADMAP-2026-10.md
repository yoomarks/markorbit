## 1. 先对齐 MO，而不是从工具倒推产品

Lite 创作要让商标代理机构把合法可用的业务资料和品牌资产，变成客户看得懂、愿意保存、能采取下一步行动的内容。具体价值是：咨询更有质量、客户解释更有效、待售商标更容易被理解、代理人专业形象更持续，且单位合格内容的制作成本可控。

MO 同时服务 MarkReg、普通代理机构 Workspace、其 Site/小程序直客。创作必须能从 Service、Trademark/Listing、Customer、Matter、Knowledge、Opportunity 等已有上下文启动；完成的内容也要回到 Inquiry、需求确认、Quote、Purchase Intent 或案件材料的既有业务流程。内容平台自身的播放量只是中间指标。

## 2. 三总监讨论后的联合裁决

| 争议                            | 最终建议                                          | 对产品的直接影响                                                                                                |
| ------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 首发轻量是否只能产提示词/草稿   | 1.0 范围可以窄，成品品质必须高                    | 专业图集、海报、品牌六图与客户资料均按真实可用成品验收                                                          |
| 模板是否限制创意                | 使用不同叙事和信息结构的模板族，结合受控视觉生成  | 模板承担准确性与批量效率；创意体现在受众选择、表达关系、真实场景与视觉方向                                      |
| 三方向六图是否太贵              | 六件可评价成品保留；素材按方向复用，选一后精修    | 六图不等于六次从零生图；弃选、失败、返工仍计总成本                                                              |
| AI 视频是否只能作背景           | 品牌概念动态、IP 叙事主镜头可以试                 | 用完整作品与增量效果证明价值，固定商标图样/事实另层合成；不能静默降为幻灯片冒充承诺的动作片                     |
| 数字人是不是视频前提            | 原片、模板动效、TTS、生成镜头独立分路             | MR-1.5 可受控数字人试点；WS-2.0 才是常规开放候选，按授权、信任、成本决定                                        |
| 本地发布助手要不要保留          | 1.5 保留 1—2 平台试点；2.0 再评价 Local Agent/MCP | 自动准备、填表、上传有价值。最终动作、账号和发布证据复用 CHANNELS，按平台能力分级                               |
| MOKI 是否每条内容重新生成角色   | 遵循当前私库 2.5D Approved Asset-First            | 已批准姿态/道具一次认证多次复用；缺姿态转资产开发。v2/Mogee 主档、不可变 release、pose 库未冻结，不能声称已激活 |
| 3.0 要不要以 3D 为中心          | 主线是规模栏目、实验、协作和版本更新              | 3D/复杂表演仅在付费需求和独立经济性验证后作为附加能力                                                           |
| 安全/许可不足是否整体否定旧方案 | 按具体实现和用途取舍                              | 保留它解决的业务需求，替换不可用/不适合的依赖；受限组件不列进默认商业生产路径                                   |

三总监保留的共同硬门：事实与授权错误不能被美观评分抵消；模型评分不能替代人工审核；成功生成文件不能替代客户理解与实际使用；版本号不能替代成熟度证据。

## 3. 版本是创作波次，发布资格另外映射

以下 1.0 / 1.5 / 2.0 / 3.0 是本次重编的**创作模块波次**，不是改写全平台发版号。

| 创作波次                  | 解决的核心问题                                     | 发布轨道建议                                                                   | 旧方案被吸收的位置                                                           |
| ------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| 1.0 专业图文与商标展示    | 一份可信 brief 变成可直接交付的图文/资料/商业方向  | WS-1.0 图文候选；MarkReg 先 dogfood，代表 Workspace 补证，M16 修订获批准后开放 | 旧 1.2 的 PNG/PDF、旧 1.3 的素材与局部编辑前移并整合；撤销只有字段的首发安排 |
| 1.5 完整视频与发布助手    | 同一任务变为完整声画视频，单段可改，能送到目标渠道 | MR-1.5 先行；普通 WS 按已验功能独立放行，不能自动称为 WS-1.0 视频              | 保留模板短片、TTS/字幕、真人剪辑、1.5 本地发布插件；数字人只做受控 MR 支线   |
| 2.0 持续创作与品牌/IP体系 | 多期、多语言、多渠道、多品牌不反复从零制作         | WS-2.0 候选与 MR Forward；白名单 BYOK、主动通信资格按原模块批准                | 保留母图、受控工作流、数字人、Local Agent/MCP、有限批量和 ICP 个性化         |
| 3.0 内容经营与规模实验    | 批量仍专业、来源更新可治理、效果和成本能优化       | Research → MR/代表 Workspace pilot → 分功能开放                                | 保留高阶广告/3D支线；主线新增规模实验、资产复用与版本运营                    |

同一代码和结果合同，通过 Installation、Product Profile、Workspace Entitlement、Role、Channel Policy、Provider Readiness 和 Maturity 决定开放资格。MarkReg Ultimate 具有先行试验资格，不意味着普通 WS 被迫承担其全部成本，也不形成 MarkReg 专属产品 fork。

### 首发六个模板族

每族至少两种不同信息结构的布局变体是**候选准入要求**，还需 Owner 冻结和样片验证。它们可共享一个准确排版引擎。

1. 问题/误区图集：一个误区 → 原因 → 例外 → 行动，而非每页三卖点。
2. 步骤/材料清单：流程关系、时间/责任分工、缺失材料和下一步。
3. 费用/方案比较：同口径比较、官费/服务费/不含项、适用条件和有效期。
4. 编辑式服务/观点海报：强主张、相关场景、证据/适用对象、明确 CTA。
5. 商标商业封面与应用拼图：原图样、品牌气质、品类/受众场景、权利事实卡。
6. 专业人物/IP栏目：作者观点、授权头像/pose、固定栏目识别与有变化的信息结构。

所有模板测中文长短文、英文、宽窄 Logo、低分辨率原图、无素材、部分缺字段、390px 手机阅读。漂亮理想样例不能证明模板族合格。

## 5. 创作 1.5：完整声画视频，加上可用的发布助手

视频按四条主路选择：准确图文动效、真人口播/原片包装、真实录屏/演示、品牌场景/概念叙事。角色 2.5D 和数字人是这些表达的可选分支。一般交付 20—60 秒，完整预览包含声音；长度和画幅按任务确定，不机械套时长。

| 功能编号                  | 输入与具体环节                                        | 必须交付                                                 | 放行与成本控制                                                          |
| ------------------------- | ----------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------------------------------------- |
| L15-01 场景/台词规划      | 已核事实与讲稿 → 每段读者问题、主张、证据、动作、时长 | 可读分场卡、完整低成本预览、修改提案                     | 先审讲稿再昂贵生成；必要条件/否定词不能为节奏删掉                       |
| L15-02 图文与商标动效     | 选中图文/品牌方向 + 准确图层                          | 30—45秒解释/推荐片、9:16主体、另画幅重新布局             | Remotion/HyperFrames/FFmpeg/adu 按样本选路；只选一个默认主引擎          |
| L15-03 原片转录与剪辑     | 自有真人原片/录屏 + 已有字幕可选                      | ASR纠错、专名词典、非破坏剪辑提案、字幕/关键词/证据画面  | 展示被删除段；保留原片与时码映射；不能只按静音删专业条件                |
| L15-04 TTS与字幕          | 已批准台词、语言、合法音色                            | 听审音频、准确字幕/时间对齐、SRT/VTT/烧录版              | 有可靠TTS时标就复用，不重复全文ASR；按段重做发音，声模许可独立核验      |
| L15-05 镜头组与局部重配   | 口播/镜头设计表 + 允许模板/素材                       | 完整镜头组、动作保护窗、字幕/声画协调、单段修改前后对照  | adu只开放验过的组/环境；改变台词长度须重新验时间窗及接缝                |
| L15-06 2.5D与有限生成镜头 | 批准IP资产、品牌场景与已选方向                        | pose组合、高亮/气泡、轻位移；可选有预算的动态概念镜头    | 新pose走资产开发；动作片不可暗降静态；生成Logo不能替代原图样            |
| L15-07 成片交付与恢复     | 逐段资产/字幕/音频/工程 + 审核                        | MP4、封面、字幕、音频、可编辑工程参数/依赖、检查报告     | 完整声画人工实看；取消/失败保留已做部分；单段重生成与全片重编码分开计量 |
| L15-08 本地发布助手       | 已审PublishPackage + 渠道账号/目标平台                | 预填配文、上传媒体、平台预览、待用户最终发布、回填证据   | 先1—2平台；Cookie留本机；页面变化/验证码/账号不符时可导出手动继续       |
| L15-09 视频效果比较       | 同一主题图文/真人/动效版本                            | 完整成本、制作/审阅分钟、实际观看分母、理解/合格咨询结果 | 图文有效不等于视频有增量；按任务选形式，禁止默认所有内容转视频          |

MR-1.5 可加入授权数字人的小样对比；普通 WS 常规开放须另验信任、中文发音、口型、肖像/声音授权、撤销与单位成本。它不能阻塞模板片和真人片。

## 8. 八种商标行业内容打法：输入、SOP、CTA、验证

这些是有具体执行路径的业务假设；本轮没有代用户公开发布、购买联系人或验证实际营销提升。

### P1 一个问题，一组解释图：知识咨询

对象是准备销售/出海的企业老板。输入为真实常见问题、法域、官方或已审知识及版本、适用条件/例外、服务入口。流程：选一个问题 → 提取结论/前提/材料 → 4—6页信息结构 → 手机全文审阅 → 图集/长文/清单 → 使用后登记来源。CTA 为“提交目标国家和商品”“获取材料清单”。

先做三个真实主题，与现有内容比较收藏/咨询质量、解释回合与成本；合格咨询须包含能分派的真实需求。标题点击好但咨询大量误解则判失败。知识来源不足时保存草稿转专业核验，不恐吓、不承诺包过。

### P2 可比的全球服务方案：询价转确认

对象是已有国家/类数需求的客户。输入为有效 Quote/PricingVersion、币种、官费/服务费、服务范围、不含项、适用条件与有效期。流程：补齐报价条件 → 同口径比较 → 一页图 + PDF + 材料清单 → 客户确认 → 经权限进入正式Quote。CTA 为“确认范围后获取正式报价”。

试三项新方案与三项相近旧流程，记报价工时、重复澄清、材料完整度、明确确认比例。私有报价不用于公开宣传；模型不能补猜价，公开低价必须有条件。

### P3 品牌用途看得见：单商标商业化

对象是获授权待售资产的持有人和潜在买家。输入为原图样、权属/展示授权、当前类别/商品/法域/状态、真实价格或询价方式、买家行业。流程：事实核验 → 3方向×2图 → 选1 → 扩2—4件场景 → 事实卡/应用示意 → Site/小程序展示 → Inquiry/Make Offer/Purchase Intent。

试三个真实获授权商标。量每详情访问的合格询价、买家能否解释匹配理由、选择/审阅时间、总费用/实际采用件。Buy Now沿M18默认购买意向；精美包装示意不变成经营/使用证据，也不证明权利适用范围。

### P4 为项目挑商标：客户短名单

对象是有行业/商品/市场/预算要求的买家。输入为已确认客户brief/ICP、获授权可售资产与权利资料。流程：硬条件过滤 → 2—4候选 → 每件给匹配与不匹配理由 → 比较矩阵 + 少量预览 → 客户选最多2件 → 深化/核验 → 询价。

三客户项目试点，量候选缩减、继续核验比例、筛选/解释工时。不要每件库存先生成六图；语义好名字不代表覆盖相应商品或检索风险合格。客户brief和预算保持私有。

### P5 代理人真人解释 + 证据画面：专业信任

对象是专业代理人的潜在客户。输入为本人授权原片、讲稿、公开可用案例/录屏、肖像/声音范围。流程：确认主张 → 转录纠错 → 静音删减提案 → 3—5镜头设计 → 准确关键词/真实证据画面 → 完整声画审核 → MP4/字幕/封面/工程。

三条约45秒真人短片，做长标题和单段改配，量制作/审阅分钟、误剪条件次数、读者复述、合格咨询/观看分母。不能编造业绩或让通用素材暗示真实客户成功。数字人另作对照变体，不预设更可信。

### P6 一个IP，一组持续栏目

对象是机构长期知识栏目。输入为已批准角色主资产/pose、风格包、已审知识和受众。流程：选问题 → 选择已认证pose/道具 → 精确图表/字层组合 → 人审角色与事实 → 图集；选中一篇做20—30秒2.5D片。

三期连载，量资产命中/复用、角色一致性、内容复述、每期工时与成本。缺pose走一次性资产开发；MOKI未冻结资产不得假称已可生产。机构可不用人物完成相同知识任务。

### P7 私域案件解释/材料包：提升服务效率

对象是已有客户面对OA、使用证据、续展或转让决策。输入为经办核准案件事实、期限来源、客户需决定项、允许收件人。流程：抽取问题/证据/可选路径 → 简明解释卡 + 完整PDF + 私聊配文 → 经办审核 → 客户回复/提交材料 → 原业务流程更新。

试三个脱敏真实任务，量材料首次完整率、补问回合、经办解释分钟、客户理解。期限/主体错误为阻断项；私域案件不得自动转公开获客故事。创作资料不等于官方答复/Filed/Completed。

### P8 一个行业变化，一个行动建议

对象是机构可服务的行业/地区。输入为获授权统计/研究、时间窗口/样本/限制、服务能力、ICP购买角色假设。流程：选行业问题 → 带限制的研究图/文章 → 专业核验 → 自有渠道使用 → 获取材料/提交计划；定向外联另审Contact来源、允许用途与抑制列表再准备草稿。

先三个公开/自有渠道主题；定向试点另取批准范围。量合格咨询/访问、合法触达后的有效回复、退订/投诉、核验和获客成本。ICP不是联系人名单，采购到邮箱不等于可营销；内容生成不自动触发采购或发送。

## 9. 两个完整创作实例：具体到页与镜头

以下是结构样例，不是法律结论、真实商标注册资料或已制作的样片。实际制作时以获授权输入替换。

### 实例 A：客户问“出海前应先准备哪些商标资料？”

目的为得到完整需求，受众为准备第一次出海的卖家，CTA为提交目标国家、商品、原图样和申请人资料。输入必须包括选定法域/程序的已审资料；若多法域差异无法简述则分稿。

| 页             | 读者问题         | 文案/视觉功能                                     | 必需证据与编辑规则                                  |
| -------------- | ---------------- | ------------------------------------------------- | --------------------------------------------------- |
| 1 封面         | 我该先做什么     | 一个明确问题 + 四类材料视觉，不承诺“一次通行全球” | 适用对象/法域清楚；封面不恐吓                       |
| 2 目标市场     | 去哪里卖什么     | 国家与商品两轴示意 + 用户填写入口                 | 商品分类/程序解释来自已审知识，示意不当法律适用判断 |
| 3 名称与图样   | 要提供哪个版本   | 原图样/文字标与商业包装示例对照                   | 登记图样与新设计区别清楚，准确文字另层              |
| 4 申请人与证据 | 谁申请、准备什么 | 按所选程序的材料清单，逐条有短说明                | 不凭模板捏造统一全球材料或期限                      |
| 5 下一步       | 提交后得到什么   | 已填/待填摘要 + 预约/需求确认CTA                  | 服务承诺可兑现；链接可访问；不得说提交即已申请      |

选择“清单”或“故事”两个布局，先小样选一；完整五页图文通过后，1.5可改为35—45秒：问题3秒 → 目标市场7秒 → 图样区别8秒 → 材料说明12秒 → 下一步6秒。实测台词决定时长，事实字层固定，录屏只用真实允许公开界面。

**检验这个打法**：读者能说出四项应提交资料；后台需求首次完整率提高、staff补问回合下降。CTA验收覆盖点击→提交/保存已填资料→形成原Owner的需求卡/待补项→可进入Workbench继续。播放量再高，若更多客户误以为“一稿适用于所有国家”，内容仍失败。

### 实例 B：一个有真实权利资料的家居类待售品牌

三方向建议为“温暖日常”“功能设计”“自然礼赠”。具体方向须适合真实商品与买家，不固定套三个奢侈风格。

| 方向     | 商业假设                      | 两张预览分别表达                            | 选中后深化                                |
| -------- | ----------------------------- | ------------------------------------------- | ----------------------------------------- |
| 温暖日常 | 家庭日用、亲和、容易记忆      | 封面表达温暖识别；拼图展示相容包装/社媒场景 | 2张包装/电商图、详情文案、20—30秒应用示意 |
| 功能设计 | 功能型产品、理性、现代        | 封面强调结构/清晰；拼图呈现产品信息系统     | 参数说明样式、电商主图、官网段落预览      |
| 自然礼赠 | 礼赠/审美消费、质感、自然语汇 | 封面营造材质；拼图呈现场景与礼盒表达        | 礼盒/赠礼场景、销售PDF与询价页            |

原图样始终独立、准确；新场景均标“品牌应用示意”。三张背景资产可以复用于六张版式，某方向有自有素材时可少生成。CTA为查看详细商品范围/权利资料、询价或出价。行业推测不会写进官方商品范围。

**检验这个打法**：买家能说出方向差异并筛掉不合适方案；有效询价/详情访问与解释工时相对原Listing有改善。CTA验收覆盖Inquiry→关联原Listing与所选方向→经办获得可继续的Work，复用原Owner。买家只觉得漂亮，却更误解权利范围，则应调整。

无障碍与双语沿主规格：键盘完成选择/排序、焦点回返、状态播报、中文IME确认不发送、reduced-motion、中文默认/英文等价。切 UI locale 不改内容语言、费用或业务状态。没有“聊天回答后忘了选择”的临时会话做法。

## 13. 大量用户成本：按成功目标核算

### 13.1 四个成本分母

技术请求均价 = 所有模型/算力/素材/许可/失败成本 ÷ 请求数。合格交付均价 = 同批总成本 ÷ 通过事实、视觉、功能门的交付数。实际使用均价 = 同批总成本 ÷ 被真正使用的成果数。有效获客成本 = 生产+分发+人工总成本 ÷ 可追踪的合格咨询数。四个数分别报告，不能只取最便宜的调用单价。

用户审阅分钟和MO雇员支持费用分开记录；机会成本可折算，但不会伪装为用户实际账单。资产开发、模板维护、闲置GPU、峰值冗余、存储/出网与失败重试都应入经营模型。

### 13.2 默认路线与升级条件

| 路线              | 适用任务                            | 默认成本策略                            | 何时值得升级                                 |
| ----------------- | ----------------------------------- | --------------------------------------- | -------------------------------------------- |
| 准确模板/CPU      | 费用/流程/知识卡、原图、PDF、多尺寸 | 批量复用、字层编辑、稳定字体            | 表达不足时先改叙事/布局，再决定新视觉        |
| 复用资产+局部AI图 | 商标商业方向、包装/场景、品牌母图   | 方向级素材共享，选中才高清/深化         | 买家理解或选用率确有增量，或缺真实所需场景   |

### 13.4 GPU自托管何时值得

比较 `云API每合格结果成本` 与 `(月固定GPU/运维/冗余成本 + 每结果变动成本×总尝试) / 合格结果数`。只有许可、质量、利用率、峰值排队与支持全部可解释，自托管才可能更便宜。量化/少步数是候选优化；商标/角色保持和可用率下降可能吞掉节省。大量Lite用户不需要自己装ComfyUI或声模。

### 13.5 预算与队列规则

先列产物和费用区间 → 预留预算 → 各阶段实耗 → 已知失败释放未用预算/核对未知扣费 → 成品/用量回执。取消不等于上游免费；来源不明的Provider结果先查状态。

同一幂等任务恢复只读已有attempt，不二次预留/扣费；Provider未知扣费查询后对账；用户额度返还与MO实际成本分别记录。任务明确承诺声画或动作时，Provider失败不能静默交付无声/静态版；需要用户接受新的交付范围。

CPU图文、转码、图像API、生成视频/数字人、发布任务分池，按Workspace公平调度。限制每用户/Workspace并发、批大小、秒数、画幅/语言、最大尝试和平台日预算。公共授权素材可按许可共享，私有原图/客户资料/作品缓存按Workspace和用途隔离。源版本、字体、模板、画幅、语言、品牌、模型/声音版本纳入缓存键，不能只用prompt。

修改没过质量门又到预算上限时，给缩范围、换模板/已有素材、人工接管或明确追加的可审方案；不能交付未合格图称成功，也不能无限抽图。

### 15.2 质量硬门与候选用户目标

硬门：事实字段、原图样、来源适用性、使用授权、未声明AI场景、敏感信息、CTA去向、关键文本缺失/溢出错误均不得放行。对公开版本的完整声画与手机阅读必须实看；OCR/检测器只辅助，不替代原图与专业事实核对。

##### 2.1 Remotion：React 精确模板与播放器

已读 README、LICENSE.md、`packages/renderer/src/render-media.ts`、`get-concurrency.ts`，查看 renderer API 和源码目录。

- `renderMedia` 接受 composition、inputProps、输出路径，存在取消信号、并发、超时、进度、帧渲染和音视频合成控制。把用户确认后的商标字段和脚本作为 inputProps，比每次让 Agent 写一套未知代码可控。
- 同一模板可产生单商标推荐、资产合集、可核对的费用分项和流程节点。字段证据来源、更新时间、推荐理由由 MO 业务层提供，不由视频框架创造。
- `get-concurrency.ts` 默认按 CPU 数限制渲染并发，具体仍受内存和视频素材解码限制；它不是跨租户任务调度器。MO 必须在已有任务体系中限制每 workspace 并发、时长、清晰度、最大重试、超时和费用预算。
- 原始商标 logo 作为固定文件图层；AI 只生成背景/产品概念示意，避免把生成变形的图样当真实注册标识。
- 官方截至本次核查的公司 Automators 方案：每成功 render US$0.01、月最低 US$100；渲染视频、音频、GIF、静态图、PDF 都计 render，Studio/Player 预览不计。符合免费资格者不需要这笔费用。允许 MO 模板/服务生成代码个性化；不允许做客户任意上传 Remotion 工程的通用代渲染绕过许可服务。上游 5.0 许可/telemetry 正在变更，固定版本再升级。
- 结论：保留为 A 级预研。每条片 US$0.01 的许可项并非必然是最大成本，开发效率、CPU/内存、返工次数、审核与媒体存储一起比较；不能为了免许可费把稳定工程路线一概排除。

##### 2.2 HyperFrames：HTML 可寻帧视频

已读 README、LICENSE、engine `index.ts`、`types.ts`、`config.ts`、`services/frameCapture.ts`。

- `window.__hf` seek contract 把页面在任意帧时间定位；动画必须能寻帧，不能把随实时时钟跑的网页直接当可靠成片。
- capture 服务实际使用 Puppeteer，等待媒体/字体/子时间线就绪，寻帧和截图；FFmpeg 编码/混音是另一个失败点。类型中明确有媒体就绪超时、媒体加载失败、音频处理失败、子时间线失败等 warnings。MO 不能把有 warning 的输出统一显示成功。
- `config.ts` 有 draft/standard/high、24/30/60fps、并发/内存、提取缓存、超时配置。frameCapture 含 static frame dedup，可以减少静止图卡反复寻帧和截图；不等于静止片段视频编码完全免费，也不保证所有页面都可去重。
- 适合行业解释视频、真实 UI 演示附文字、logo/费用说明、代理人真人口播覆盖图卡。字体、素材、时钟和模板固定后再讨论可复现；网页外链变了同输入也可能不同。
- 不建议每客户从零生成任意网页代码。先发布经过审核的 HTML 模板，按变量套版；需要新风格时作为模板创作任务，和客户业务内容生成分开。
- 结论：仍是 A 级候选，与 Remotion 使用同一验证数据比较中文/双语文字、logo、字幕、失败恢复、成本和维护。先选择一个默认视频 worker；另一个只保留适配边界，避免同时养两套主模板。

证据：[seek/错误类型](https://github.com/heygen-com/hyperframes/blob/621ddd46934316fe81f1b6254e4ae57bc8ec5ada/packages/engine/src/types.ts)、[配置](https://github.com/heygen-com/hyperframes/blob/621ddd46934316fe81f1b6254e4ae57bc8ec5ada/packages/engine/src/config.ts)、[实际帧捕获](https://github.com/heygen-com/hyperframes/blob/621ddd46934316fe81f1b6254e4ae57bc8ec5ada/packages/engine/src/services/frameCapture.ts)。

##### 2.3 Playwright/Chromium：PDF 与复杂版式

已读 README 和 `packages/playwright-core/src/server/chromium/crPdf.ts`。

- PDF 实际调用 Chrome DevTools `Page.printToPDF`；支持纸张、页边距、页眉页脚、页面范围、CSS 页尺寸、tagged/outline 等。源码默认 printBackground、preferCSSPageSize、tagged、outline 均为 false，产品模板需显式配置。
- 适合多国家费用清单、报价方案、某客户精选商标推荐册、来源解释页；客户无需看内部渲染工具。
- 报价中的官费、服务费、税/汇率、有效期与版本来源来自 MO Quote/Global，不可由 AI 顺口生成。POA/客户确认表是受规则约束的业务文件，应独立模板和审查，不能与营销海报共用随机风格。
- 长表格分页、中文字体、页眉重复、logos 和二维码扫描需验证；截图和 PDF 不能只验证“文件存在”。
- 规模使用靠复用浏览器、隔离 context、固定本地资源、限制并发和字体缓存；任意网页输入必须限制网络和文件读取，不能开放通用 SSRF 渲染入口。
- 结论：与图像模板一起放在 1.0 核心验证，PDF 比全生成视频更接近真实商标销售/服务交付。

证据：[Chromium PDF 实现](https://github.com/microsoft/playwright/blob/4357c237cfde9135fb5b7894c22a45468321a973/packages/playwright-core/src/server/chromium/crPdf.ts)。

##### 2.4 Satori + resvg：高频低成本事实图卡

已读 Satori README、LICENSE、`src/satori.ts`、`src/font.ts`；resvg README、Cargo.toml、`crates/resvg/src/lib.rs`。

- 当前 Satori 使用 Taffy 处理 flex/grid/block，自有文字布局；并非浏览器完整 CSS。不要沿用过时的“只支持 Yoga/flex”描述。表格、ruby、部分布局/Unicode双向文字仍有限制。
- 当前支持 TTF/OTF/WOFF，尚不支持 WOFF2；需显式传入字体 buffer。已有 HarfBuzz shaping；混排 RTL/LTR 仍不能按浏览器顺序保证。中文/阿拉伯商标名称不能用“Unicode 支持”代替真实验收。
- font.ts/satori.ts 有字体解析和 shaping 缓存，适合模板批量任务。相同模板版本、字体、数据快照、locale、图片hash形成缓存键；只改 CTA 时重排图层，不重新生图。
- resvg 用 usvg 解析树、tiny-skia 输出像素；产物是 sRGB，静态 SVG，无脚本/事件/动画。字体和图片准备后作为稳定 PNG 出口，不承担文本理解。
- 三商业方向×两张成果，不意味着调用图像模型六次：可复用 logo 原件、方向级一张创意背景，再分别排出封面/资产拼图，或采用完全模板路线。用户选择方向后才做高成本场景素材。
- 结论：A 级主路线，复杂海报使用 Playwright 截图做质量与兼容兜底；renderer 原因和失败应自动处理，用户选择表达目的和预算即可。

证据：[字体实现](https://github.com/vercel/satori/blob/cc3119fa2961cd8976e13940eda4de9b8bd2d991/src/font.ts)、[SVG编排](https://github.com/vercel/satori/blob/cc3119fa2961cd8976e13940eda4de9b8bd2d991/src/satori.ts)、[resvg像素入口](https://github.com/linebender/resvg/blob/b12646b228678a305bbdc8f5e13c6b361ae25091/crates/resvg/src/lib.rs)。

##### 2.5 Sharp：原图保护、尺寸衍生、图层合成

已读 README、LICENSE、`lib/resize.mjs`、`lib/composite.mjs`。

- 用 contain 保持商标 logo 比例、透明背景和完整图样；cover 仅适合允许裁切的背景，不适合剪掉商标边缘。

##### 2.10 Short Video Maker：组合路线保留、真实行业内容须改

已读 README、LICENSE、`ShortCreator.ts`、`libraries/Remotion.ts`、`Kokoro.ts`、`Pexels.ts`。

- 实际流水线是逐场Kokoro配音→Whisper字幕→Pexels背景→Remotion，启动时bundle模板一次；这是无需生成式视频模型的低成本路线，可保留借鉴。
- Pexels选片随机；原词找不到会使用nature/globe/space/ocean等joker词。对MO“解释概念的氛围B-roll”可接受有标记的候选；对“商品真实用途/商业使用证据/商标权利事实”必须拒绝这种回退。
- ShortCreator队列是内存数组，源代码留有mutex/semaphore TODO，状态靠排队记录/文件存在。进程重启、跨worker并发、取消与成本预占不是现成能力；应接MO已有任务体系，不fork第二套真值队列。
- 固定README明确英语配音、tiny.en/base.en/medium.en，Windows不受支持；最近push为2025-06-21。不能把样片当中文代理人工作站验证，不因这一点否定其pipeline设计。
- 若TTS已返回可靠词时间戳，不必为了字幕再全跑Whisper；用户原始真人视频才需ASR并校正商标专名。
- 结论：B级参考；分别替换为 MO TTS/Caption/Asset/Renderer Provider，保留其CPU路由和资源上限经验，弃用随机通用B-roll作为行业正确性的依据。

证据：[队列和场景流水线](https://github.com/gyoridavid/short-video-maker/blob/9bb9a212ced86caa7e09099c382da1a44d638760/src/short-creator/ShortCreator.ts)、[Pexels随机回退](https://github.com/gyoridavid/short-video-maker/blob/9bb9a212ced86caa7e09099c382da1a44d638760/src/short-creator/libraries/Pexels.ts)、[Remotion封装](https://github.com/gyoridavid/short-video-maker/blob/9bb9a212ced86caa7e09099c382da1a44d638760/src/short-creator/libraries/Remotion.ts)。

##### 2.11 FFmpeg：有价值的低成本基础视频路线

已读LICENSE.md、源码 `vf_overlay.c`、`vf_drawtext.c`、`af_loudnorm.c` 入口与许可。

- 可把准确图卡/原始logo叠到背景或真人片、做静态图卡镜头切换、配音/字幕/CTA、音量归一；无需每次逐帧重新跑复杂DOM。它适合基本款，不需要强迫所有商标销售视频达到大片动效。
- `drawtext`有字体shaping依赖；关键精确文字可先由Satori/resvg生成图卡再overlay，减少shell转义、字体差异及换行风险。
- 通过ffprobe获取帧数/音轨/时长；技术校验只能证明文件符合合同，不能证明广告转化或法律表述正确。
- 配置依赖决定license；libx264/libx265等涉及GPL，nonfree组合可能不可再分发。内部worker、客户端打包和提供下载有不同许可问题，必须以实际build manifest处理；“作为单独进程”本身不能免除发行义务。
- 结论：A 级底层和1.5基本款；与Remotion/HyperFrames不是二选一，前者负责轻处理/交付，后者负责高级图形寻帧。

证据：[实际许可组成](https://github.com/FFmpeg/FFmpeg/blob/e0e6ca1e29ef3f6b1e9b7d8656fe341eee8cf647/LICENSE.md)、[overlay源码](https://github.com/FFmpeg/FFmpeg/blob/e0e6ca1e29ef3f6b1e9b7d8656fe341eee8cf647/libavfilter/vf_overlay.c)、[文字滤镜](https://github.com/FFmpeg/FFmpeg/blob/e0e6ca1e29ef3f6b1e9b7d8656fe341eee8cf647/libavfilter/vf_drawtext.c)。

##### 2.12 Video Pipeline SDK：可执行工序，不是“质量与转化保证”

已读README/INTERFACE/ATTRIBUTIONS、`pipeline/run.py`、`gates/aggregate.py`、`check_match.py`、`check_layout.py`、`tools/check_sync.py`。

- 输入原片/稿/brief/brand，产物成片、design-table、asset-match、gate-report、sources；退出码区分完成、异常、门失败、等待回答。运行态question/answer协议和checkpoint可借鉴。
- `run.py`确有单入口和恢复，但分场、设计表、build等可等待执行者提供，配置命令与外部Agent还需负责创意动作；不能将机器入口等同无需人工的全自动编导。
- **素材台词对位门**只检查文件存在、片段时间合法、台词非空，并可生成抽帧核对表；不会自动判断素材真的表达了那段商标事实。
- **排版门**依据输入rect检查边距/未声明重叠；最大元素是提示，不自动理解单一视觉焦点、字体清晰度或实际截屏溢出。
- **同步门**对原音频/输出音频做互相关，估计音轨时间偏移；不看嘴唇图像，不等于口型视觉验证。还应验证相关度、采样率、窗与编辑映射，不能只看偏移在15ms内。
- 门聚合执行配置命令并按退出码合并报告，MO应固定审核过的gate版本和配置，而非由任意任务输入shell命令。两次approval答复应转成MO业务对象版本与权限校验，不把本地JSON的字符串approve当授权凭据。
- 素材/音效代码MIT不能扩张成全部资产MIT。ATTRIBUTIONS列av/remotion-bits、naveen-annam/hollowenshot示例、Remotion effects、Mixkit、马善政字体、受限LUT；未核身份/版本/许可需留待专项确认。
- 结论：B级产线合同参考；1.5先保留机械门和人审包，2.0再按真人口播业务有条件扩展。默认16:9等特定生产风格不强制绑定MO平台图文/竖屏用途。

证据：[合同](https://github.com/mengyuyuan/video-pipeline-sdk/blob/41ea28cfa21a40b3e7d9bd33366d30adc6e1bd2d/INTERFACE.md)、[运行机](https://github.com/mengyuyuan/video-pipeline-sdk/blob/41ea28cfa21a40b3e7d9bd33366d30adc6e1bd2d/pipeline/run.py)、[对位门的实际判定](https://github.com/mengyuyuan/video-pipeline-sdk/blob/41ea28cfa21a40b3e7d9bd33366d30adc6e1bd2d/gates/check_match.py)、[排版门](https://github.com/mengyuyuan/video-pipeline-sdk/blob/41ea28cfa21a40b3e7d9bd33366d30adc6e1bd2d/gates/check_layout.py)、[互相关同步](https://github.com/mengyuyuan/video-pipeline-sdk/blob/41ea28cfa21a40b3e7d9bd33366d30adc6e1bd2d/tools/check_sync.py)。

#### 3. 保留旧路线而按业务、预算分流

| 任务                  | 经济默认路线                                   | 增强路线                            | 何时不升级                                           |
| --------------------- | ---------------------------------------------- | ----------------------------------- | ---------------------------------------------------- |
| 商标资产推荐/销售资料 | 真实logo和事实字段→模板图卡/PDF/可更新分享页   | 用户选中的商业方向加AI场景/包装示意 | 只是改价、改CTA、改尺寸/语言，不重生全部图片         |
| 商标知识/规则解释     | 有依据的稿和流程图→图文/配音图卡视频           | 真人口播配图，少量有来源的B-roll    | 泛素材不能证明权利事实，不为凑“大片”调用昂贵视频模型 |
| 多国家报价说明        | Quote数据快照→费用表PDF/动态图卡               | 选国家后配音或真人解释              | 官费/汇率/有效期过时先更新数据再出片，不渲染旧报价   |
| 代理人个人IP          | 原始真人素材→ASR纠错/少量剪停顿/准确字幕       | adu镜头组或高级动态图形、授权数字人 | 用户没有合适原片时，可先用TTS/图卡，不强制数字人     |
| 商业潜力演示          | logo锁定→AI辅助场景+准确叠加标签，显著说明构想 | 选中方向的短B-roll/形象视频         | 创意应用示意不能作为已存在经营/使用证据              |

三阶段预算表现建议：基础模板（确定性处理）、增强创意（选中方向少量AI素材）、高阶视频/数字人（显式报价与预占）。这是技术层处理选择，用户看到“要用于什么目标、可花多少、预计多久”；不把renderer品牌作为每任务必答问题。

#### 4. 大量用户成本：必须按已采用成果核算

每月成本至少为：

`LLM/图片/视频/TTS/ASR API + CPU秒×单价 + GPU秒×单价 + RAM峰值/并发 + Renderer许可 + 存储GB月 + CDN出网 + 失败重试 + 模板维护与人工审核`。

关键控制：内容和事实确定后重渲染不重推理；方向选中后再贵生成；素材/配音/模板/content hash缓存；预览先图卡或播放器，用户确认再成片；按租户公平排队、预算预占、取消、重试上限和失败释放；同时记录候选生成数、实际采用数、送出数与获客转化，避免只看“产了多少”。

举例（规划假设，不是用户量预测/实测报价）：10,000名月活，每人4张图+1份PDF，20%的人再出1条30秒30fps视频。静态成果50,000，视频2,000，视频帧量1,800,000。若静态用Satori/Playwright、视频用Remotion且需公司Automators许可，则许可本身按当前规则为 `max(US$100, 2,000×US$0.01)=US$100/月`；若全部静态也走Remotion，52,000 render的许可项为US$520/月。两者都还没有CPU/媒体/模型成本；不能把US$100写成整个平台视频成本。此比较支持将静态与视频分流，并不证明另一视频框架一定更便宜。

前期不要承诺永久无限生图/视频。基础模板编辑和确定性导出可低价/较大配额；增强素材、生成式视频、数字人按实际成本独立配额或付费。因业务需要的授权/证据检查是必要投入，不能为省钱省去。

#### 5. POC 必须是行业验证，不是10秒样片即结束

每renderer共用同一测试集：中文长商标名/短英文名/复杂图样/透明logo/原图低分辨率/多国家价表/临近过期数据/中英双语/如涉及中东则RTL组合，覆盖缺字段和素材授权不足。

测量：用户任务成功率、事实字段与批准版本一致、logo几何/裁切、文字溢出/遮挡、二维码可扫、PDF分页、字幕专名、音画时间、失败恢复、取消释放、同输入重放、一千任务批次的p50/p95时间/内存/CPU/出网/总成本、人工修改率。门通过不等于商业成功。

商业实验共同验收：与“用户现有普通海报/文案”对照，以有用咨询/有效商机/精选资产点击和成交辅助为主要结果；CTR/播放量是中间指标。为知识教育、交易推广、报价转化、客户服务分别设目标和样本，不能把一个平台热门脚本默认当行业内容打法。

#### 6. 对1.0/1.5/2.0/3.0路线的输入建议

- **1.0**：业务成果合同、品牌/客户/商标事实可确认、三方向×两图、精确图卡/资产拼图/PDF/分享页、局部修改版本、来源/有效期/手动发布与反馈。图文模板成本低，AI增强按选择和预算触发。

#### 3. 从通用工具到真实商标内容的加工合同

语音/剪辑工具本身不会判断商标法律、交易权利或营销有效性。MO 至少增加以下合同：

1. **displayText 与 spokenText 分开。** 画面保持商标名/注册号/币种/日期原值；口播转换只有经确认的读法。例如注册号应逐位读，报价中货币与计费单位不能遗漏；商标名称可保存品牌认可的发音。口播读法变更不改变业务事实。
2. **原始转录与修正稿分开。** 保存 source audio hash、ASR provider/model/version、原始 words/timestamps、候选词典修正、用户确认与 revision。不能静默“纠错”为另一个客户/另一件商标，也不能通过 ASR 推断实际商标状态。
3. **剪切是有理由的提案。** cutWordIds / CutRange / keepReason / protectedRange 与输入版本绑定。保护“尚未”“不保证”“仅限”“官费另计”“申请中”等影响结论/报价范围的语句；低置信/无法对齐时转人工复核。静音节奏检测不负责删法律限定语。
4. **输出时间映射统一。** 字幕/商标卡/CTA/证据画面共享 source→output 时间映射。剪了前段，后续字幕必须重映射；不能按原时间直接烧录。修改字幕可无需重转写音频。
5. **证据素材保真。** 客户或交易方名称/隐私可按授权去标识；官方页面截屏须保留来源/抓取时间/用途。AI 背景可补氛围，不生成看似官方结论的证据。
6. **交付与发布分开。** rendered 不等于 reviewed，prepared 不等于 sent，user_marked_published 不等于 remote_verified。发布包绑定最终内容版本与受众/平台；重试不能使所有平台再次发布。
7. **被关闭的 Provider 不拖垮创作。** 保留文案、项目、媒体与导出。字幕 ASR 不可用仍可导入 SRT/手工修改；TTS 不可用仍可用户音频或无声动效；渠道失效仍可手动发布包。不能把失败素材假标成“完成”。

#### 5. 大量用户时的成本与试验任务

##### 成本必须以“可用交付”计量

每条成片总成本 = 脚本与修正模型成本 + ASR音频分钟成本 + TTS字符成本 + 对齐成本 + 渲染CPU/GPU时间 + 媒体存储/流量 + 失败重试 + 人工复核成本 + 许可/运维分摊。开源本地处理不是零成本，云单价便宜也不代表返工少。

- TTS缓存键包含脚本revision、voice/model、读法词典、语速及音频参数；voiceover不变时改封面/CTA/字幕样式不重生人声。
- ASR只在 source hash 或模型/纠错目标改变时重新运行；人工文稿修正不再次上传整条视频。
- 先提案、再720p短片段预览，最后1080p输出；不每次用户输入都渲染整片。
- 先做CPU模板/原声/字幕线，GPU只为已选高价值质量档或无法达标的任务；批ASR增加峰值内存，需并发/时长上限。
- 机构预设与可重用镜头/栏目降低人工策划成本；风格模板不能替代真实商标信息。
- 本地插件减服务器媒体加工负担，但安装、系统适配、更新、用户支持与平台网页变动是固定成本，必须计入。

#### 7. 商标内容与大规模成本的共同验收法

- **事实正确**：固定商标图样的来源hash与图层；案号、国家、类别、状态、金额、日期来自可追溯业务事实；AI商业想象与资产法律状态分字段。包装/门店展示标记概念呈现，不能伪装成真实使用证据。
- **可编辑**：对广告语/背景/比例/局部镜头的调整都有前后差异和费用预估；精准字段不重绘；保持旧版与资料依据。
- **可成功**：在相同内容主题与受众条件下，对比模板/生成/混合；看专家通过率、修改耗时、合格询盘率或任务完成率，不能仅看曝光/播放数。
- **可支付**：每条内容成本记录LLM、图生成、视频生成、TTS、QC、渲染、存储/分发及失败消耗；“单位合格内容成本=总实际生产费用/符合发布合同的结果数”。大规模预算还需闲置GPU与峰值SLA，不能只算一次成功推理。
- **3方向2图**：仍是6张交付物，不等于6次从零生成。每方向的封面、资产拼图可共享原商标/背景/行业资产、模板和颜色体系；只为真正缺少且能提升评估的视觉生成新素材。
- **缓存**：公开且许可允许的素材可共享字节；用户商标与私有品牌素材按租户/授权隔离；过期事实不能通过内容hash缓存继续当现时事实。
- **Provider开关**：停止某一Provider时保存已完成文案/原图/版本，可导出或换明确授权的路径；不得承诺图像编辑被关闭后自动新增付费调用。
- **先预研后经营承诺**：以上仓库没有一套已经在MO被本次动态验证的完整商业内容打法。主方案应规定低成本路线/混合路线/高质量路线同题bake-off，只有验证收益或可用性才升默认策略。
