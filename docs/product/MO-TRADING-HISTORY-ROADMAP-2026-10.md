# MO 闲置商标交易：历史恢复、版本划分与开发计划

日期：2026-10-09，Asia/Shanghai。记录 ID：TRADING-HISTORY-20261009。状态：历史汇编与新规划提案，待 Product Owner 评审；本稿不批准运行时开发、采购、发送、收款或转让。

## 1. 结论与范围

闲置商标交易应沿“有授权的资产 → 可理解的商业展示 → 有条件的买家需求 → 可跟进的意向 → 有证据的成交和转让”发展。图文、视频、估价、推荐与联系人采购都是这条链路的工具，各自需要证明效果和成本。

建议四个波次：**1.0 自有渠道的待售与意向闭环；1.5 更好的展示、寻标与匹配；2.0 团队销售和有证据的交易交付；3.0 经验证的跨 Workspace 市场。** 不能把旧 PRD 中的整个 Marketplace、资金托管和深度创作同时塞入首发，也不能因此丢掉这些长期方案。

本次恢复的依据包括：原始 Trading PRD、9月6日与7日两个开发包、商业价值图谱 v1.2、早期商品机会引擎和决策稿、最新总规格 v0.4 的 M17/M18、现有实现、GitHub 讨论，以及本日已形成的 Creator、Brain、Capabilities、ICP 研究。下文逐项区分历史想法、已有批准、当前实现和本次提案。

### 2.1 原始完整链路与现行首发的关系

原始愿景是：Trademark → Understanding/AI Tags → BrandDNA → Benchmark → 三方向 → 六张提案 → 人工选择 → Deep Build → BrandBible/Showcase → Pricing → Listing → Discover → Inquiry/Offer → Transaction Room → Transfer → Aftercare。

现行批准的 WS-1.0可以先从“管理且获授权的资产、最小正式展示、复核上架、三种意向与员工跟进”切入。BrandDNA、方向、Showcase等已有资产继续复用；完整 Deep Build、自动估价与跨机构市场不成为首发依赖。**实现仍须满足现有合同：‘不阻塞 Deep Build’不能解释成伪造 Showcase 或绕过正式素材审查。**

## 7. 商标行业的三条内容打法与实验

| 打法           | 目标对象与内容                                                                     | 行动与归因                                                  | 验证                                                                                  |
| -------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| A 资产激活     | 对合法可售资产说明权利、用途、适用/不适用买家；准确封面+真实场景或标识概念的应用图 | 同资产详情→询价/出价/购买意向；回流到资产和展示版本         | 完整资产上架耗时、合格意向率、权利误述、人工核验成本；不能只报播放/收藏               |
| B 买家寻标     | 有实际市场/商品/预算的经营者，收到2–4件短名单、比较矩阵与每件购买理由              | brief→候选→反馈→少量深化→询价；记录淘汰原因                 | 硬条件错误、候选接受、询价质量、是否推进条款；无匹配同样是有效结果                    |
| C 代理私有销售 | 机构对已有获准客户展示适合其业务的组合、机构品牌、专业下一步                       | 私有推荐链接→明确需求→员工跟进；外联另遵循Contact与发送边界 | 客户关系/隐私、真实回复与qualified intent、跟进速度、服务收入；不把机构客户转成MO客户 |

推荐先选**3–5个试点Workspace、30–50件确有授权的资产、2–3个由库存决定的行业**，观察4–6周。另取至少30次真实、可记录的买家评估，数量不足就延长/缩小结论；不能为了样本目标制造询盘或保证成交。以上是本次试点设计，不是已同意的规模或工期。

分开比较：事实说明页、商业理由页、商业理由+应用视觉、可选视频。尽量固定同一资产/卖家/价格/渠道/时间窗，随机或配对分配真实买家，分别观察文案、六提案和视频的增量。先不同时改价格和推广量，以免把流量效果误认为创作效果。

### 7.1 成功指标的精确定义

| 指标             | 分子/分母及来源                                                                                 | 如何使用                                                                               |
| ---------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 可售上架完成率   | 获授权且通过资格资产中，完成真实渠道发布的资产                                                  | 不能用Studio开始数代替可售资产分母；另保留历史Studio→Listing指标                       |

## 8. 大量用户的成本与方案选择

### 8.1 按资产价值和动作阶段消费

| 层级                  | 典型输出                                            | 默认成本策略                                                                                          |
| --------------------- | --------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 基础待售              | 事实卡、授权/风险、准确原图、简短用途、少量模板面板 | 规则/现有数据/缓存、确定性文字和图层、复用获授权素材；不默认昂贵图像生成                              |
| 三方向探索            | 三商业方向、六张完成质量的提案                      | 共用事实与准确图层、共享产品/场景素材；只对必要主视觉生成，先尺寸适配再导出；不能用降低完成度控制成本 |
| 选中深化              | 2–4或标准约6项行业应用                              | 选后生成；局部编辑优先；用户明确追加内容再计预算                                                      |
| 高意向短名单/重点资产 | 客户专属比较、详细应用、可选短片                    | 按真实需求升级；模板动效/已有镜头/准确字层优先；生成视频镜头为可选高成本路线                          |

### 8.2 成本公式与敏感性示例

`单资产成本 = LLM/研究 + 渲染与存储 + 独立图像调用数×实测单价×(1+重试率) + 视频/声音 + 联系人 + 人工核验 + 渠道/支持`。

六张交付图不必等于六次独立图像模型调用：可通过准确字层、模板和合法复用素材组成六张完整作品。反过来，一个 Run也可能有多次重试与导出，不能把用户次数当模型或render次数。

以下仅为**人民币假设值的预算敏感性**，不是供应商报价：非图像技术成本0.60元、人工分摊2.00元、重试率10%；暂不计视频、联系人与交易支持。

| 独立图像调用数 | 每次0.20元 | 每次0.80元 | 每次2.00元 |
| -------------- | ---------: | ---------: | ---------: |
| 6次            |       3.92 |       7.88 |      15.80 |
| 12次           |       5.24 |      13.16 |      29.00 |

旧 ¥9.9/完整 Run可能在某些路线覆盖成本，在另一些路线失效；加入核验、支持和失败调用后更需实测。用可用交付而非成功请求计算成本。若10,000资产只有20%进入深度Studio，应分别预算8,000件基础展示和2,000件深化，不能统一乘重度成本。

## 9. 行业事实与证据规则

首个真实交易交付试点建议选一个法域及2–3类需求，不把全球数据覆盖直接解释为全球转让服务准备完毕。商品语义、核定商品、关联商标、共同权利人、当前名称、许可与限制都应进入核验清单；模型做候选和提示，正式专业结论有来源与责任人。

以中国为例，CNIPA《商标转让程序的指引》要求真实转让意愿，并说明相同/类似商品上的相关相同或近似商标应一并转让等情形。官方答复还说明同一注册号的多类别商标不能仅选择其中一类转让。因此，候选商品与单一Nice类别匹配不足以完成交易核验，可能需要关联资产包及专业复核。[法律来源L01/L02；核对日2026-10-09]

这里只使用这两个官方来源支撑上述中国范围规则，不推导其他法域规则、不规定税务算法，也不把AI使用概念图作为真实使用证据。
