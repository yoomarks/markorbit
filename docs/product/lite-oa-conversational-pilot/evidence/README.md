# Lite OA conversational workbench visual evidence

The runnable fixture preview is available at `/oa-workbench-preview.html`. Its query parameters are
`scenario` (the documented state-matrix value, plus `STORAGE_FAILURE`), `locale=en` for the English
entry state, and `session=memory` for a draft without a trusted principal.

The Playwright acceptance journey exercises that direct preview entry and writes deterministic
full-page screenshots here for the desktop and 390px projects. They show the same fixture-bound
exact Workspace, actor, Matter, Trademark, document/version, two source-linked issues, editable
professional review, and explicit Demo boundary. Storybook remains the bounded state catalog; the
direct preview is the user-facing review surface and does not create a production OA route.
