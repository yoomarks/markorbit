# Accessibility Baseline

Target WCAG 2.2 AA. Use semantic landmarks/headings, associated form labels, described errors, text-and-symbol statuses, visible focus, logical tab order, keyboard-native controls, sufficient contrast, reduced-motion support, and polite progress announcements. Alerts reserve `role=alert` for urgent/error or the mandatory fixture disclaimer. Automated Testing Library and jest-axe checks supplement—not replace—keyboard, screen-reader, zoom, small-screen, and visual review. Invalid ARIA and missing labels are release blockers.
