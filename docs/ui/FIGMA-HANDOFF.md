# Figma Handoff

Figma is currently connected with **Starter plan / View seat**. Automation cannot create or edit a design file, and this is not a blocker. No edit attempt was made.

For this phase, UI Briefs, typed tokens, component code and Storybook are the design delivery source. Engineering truth is the versioned token and component code; Figma is for later collaboration and visual review. The two surfaces must share versions and change references and must not drift independently.

When edit access is available, a designer should import/synchronize Color styles, Text styles, Spacing variables, Components, Variants and Page templates. Component properties should mirror TypeScript contracts; fixture, error and permission variants must accompany ready states. Record code commit and Figma version in the review handoff. Figma remains a handoff/Code Connect surface, not a substitute for contracts, stories or tests.
