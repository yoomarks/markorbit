# markreg.com UI Brief

**Users/job:** enterprises, brand owners, founders, and ordinary applicants need legal complexity translated into a clear, cautious next decision.

**IA:** Visitor → AI Consultation → Account → Guided Intake → Recommendation → Plan → Quote → Payment → Documents → Order/Matter → Professional Review → Filing/Fulfillment → Portal → Lifecycle. This task implements only Recommendation Comparison: goal summary, A/B/C choices, assumptions, limitations, and continue action.

**Behavior:** desktop compares three equal cards; mobile stacks A/B/C while preserving option codes and recommendation label. Tone is spacious and explanatory. All shared page states apply; partial/stale input disables unsafe continuation, while recoverable errors retain selection. A recommendation, provider return, or payment never signals official truth, authority, acceptance, filing, or completion.

**Accessibility/acceptance:** native buttons expose selection, labels are textual, and warnings are prominent. Storybook has desktop/small-screen fixtures. Future Playwright path: review goal → compare A/B/C by keyboard → select B → read limitations → continue; API and full customer journey are out of scope.
